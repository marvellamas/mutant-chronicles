Soglie cumulative PX

Avversario principale al 100%; ulteriori unità, anche della stessa specie, al 50%. Numero PG: max(0,50; 1+0,10×(4−N)). Arrotondamento una volta per incontro. Le sfide rituali indivisibili contano come un solo avversario.

Backup, ripristino e integrazione

Per correggere una partita: Archivio partite → Modifica tutti i dati → cambia i voti o qualsiasi altro campo → Salva modifiche. Il riepilogo viene ricalcolato immediatamente. Quando salvi, l’app scarica per sicurezza una nuova copia HTML che contiene l’archivio aggiornato. Apri quest’ultima se la memoria locale del telefono non è persistente.

I dati restano nel browser/dispositivo. Non vengono automaticamente sincronizzati con Google Drive né con l'app di Marcello. Esporta periodicamente un JSON, che potrà servire anche per integrare il modulo nel progetto.

Attenzione: cancellare dati del browser, aprire il file in un altro browser o utilizzare la modalità privata può rendere inaccessibile l'archivio locale senza un backup JSON.
