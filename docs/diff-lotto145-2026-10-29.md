# Lotto 145 — 29/10/2026

## Parte A — Le cartelle dei personaggi veri non si toccano per sbaglio

Nel lotto 144 una prova nel browser aprì la cartella vera perché in `.claude/launch.json` il flag era `--personaggi=` invece di `--cartella=` e il server lo ignorò. Ora sono tre meccanismi, non una regola scritta.

1. **Un flag che non esiste ferma il programma** (`tools/argomenti.mjs`): «non conosco `--personaggi`: forse intendevi `--cartella`?», codice di uscita 2, nessuna cartella aperta. Vale per `server.mjs` e per `salva-sessione`, `migra-talenti`, `pulizia-personaggi`, `dati-locali`, `esito-aggiornamento`, `aggiorna-avviatori`, `console`, `riavvia` (elenco unico in `ARGOMENTI`). Gli argomenti senza «--» (comandi, percorsi) non si controllano.
2. **Una prova non apre la cartella vera** (`tools/protezione-reali.mjs` → `controllaAvvioDiProva`): un avvio è «di prova» se la porta non è la 3000 o se indica cartelle a mano; allora il server rifiuta di partire (codice 2, messaggio con le cartelle sbagliate) se una delle sue cartelle (personaggi, tavolo, scontri, nemici, veicoli, scene, mappe, musica, galleria, px, salvataggi, autosave, config-salvataggi) è «vera». Con `--cartella=` le cartelle non indicate stanno accanto a quella di prova (prima stavano in quelle dell'app: era il secondo buco). `--dati-reali` (senza cartelle indicate) accende apposta il server vero su un'altra porta.
   - **Come si riconosce «la cartella vera»:** le cartelle di dati accanto a `server.mjs` (e `PersonaggiBackup/`) e la cartella dei dati scritta nel profilo di Windows di questo PC (`%APPDATA%\Mutant\dati.json`, `tools/dati-pc.mjs`). Il profilo conta solo se è quello vero: con `MUTANT_CONFIG_DIR` (profilo di prova, come nei test) la sua cartella dei dati è una prova. I percorsi si confrontano risolti (nomi lunghi, maiuscole, collegamenti), anche per file che non esistono ancora.
3. **Scrivere è un'altra cosa che leggere** (`installaGuardiaScrittura`): ogni scrittura (scrivere, aggiungere, creare, spostare, copiare, cancellare, flussi; sincrone, con promesse, con callback) dentro le cartelle vere lancia `ScritturaRifiutata` con il percorso e il perché. La installa il server di prova e `tests/profilo-di-prova.mjs` (tutti i test girano con la guardia).

Altri flag sbagliati: nessuno trovato in `.claude/launch.json` (ora corretto), nei `.bat` e negli script (controllo automatico in `tests/protezione-reali.test.js`). Il solo caso era `mutant-prova-143`.

## Parte B — Il bestiario online sui browser vecchi

La pagina del lotto 144 apriva le schede con `DecompressionStream` (Chrome 80, Firefox 113, Safari 16.4): un iPad fermo a iOS 15 o un tablet Android con un browser vecchio avrebbe visto solo un messaggio.

- Ora le schede sono **deflate grezzo in base64** e la pagina le apre con una sua `inflar()` in ES5 (algoritmo di puff, 30 righe, `INFLATE_JS` in `tools/bestiario_pagina.mjs`), più la lettura UTF-8 con ripiego (senza `TextDecoder`). Niente funzioni recenti del browser. Peso: **514.963 byte (0,51 MB)**, come prima (+3 KB); in trasferimento circa 0,28 MB.
- Se qualcosa non va, la pagina non resta muta: «Non riesco ad aprire le schede su questo browser (motivo)…»; senza JavaScript (o con uno che non parte) il messaggio dice di che cosa serve, e il testo del «Manuale» si legge lo stesso (è HTML normale).
- `NodeList.forEach` e `String.normalize` hanno il ripiego; lo script non usa frecce, `let`/`const`, classi, template, `async`.
- **Provato** nel browser (Chrome 152, l'unico disponibile) in una pagina con `DecompressionStream`, `TextDecoder`, `NodeList.forEach` e `normalize` tolti: 451 schede, 1258 testi comuni, ricerca «dragomedusa» → 2; dati rotti → il messaggio. **Non provato su browser vecchi veri.**
- Da quale versione funziona (per costruzione, dalle funzioni usate): lo script (ES5, `Uint8Array`, `atob`, `dataset`) da Chrome 8, Firefox 6, Safari 6. Il layout: variabili CSS da Chrome 49, Firefox 31, Safari 9.1 (prima i colori mancano ma il testo si legge); griglia delle schede da Chrome 57, Firefox 52, Safari 10.1 (prima una colonna sola). Barra di ricerca fissa in alto da Safari 13. Per le schede a colori e a griglia: Chrome 57+, Firefox 52+, Safari 10.1+ (iOS 10.3+). L'app Mutant vera è più esigente (importmap: Chrome 89, Firefox 108, Safari 16.4, `docs/cache.md`).
